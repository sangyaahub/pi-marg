# Support

Use [GitHub Discussions](https://github.com/sangyaahub/pi-marg/discussions) for setup questions and workflow ideas.

Use [GitHub Issues](https://github.com/sangyaahub/pi-marg/issues) for reproducible bugs and feature requests. Include your operating system, Pi or OMP version, installation source, relevant commands, and redacted output.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
