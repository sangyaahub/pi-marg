argument-hint: [plan | code]

Load `auto-mode-router` and the native Pi runtime reference.

- `plan`: activate Stage C, review the authoritative plan and highest-cost risks, then record the verdict.
- `code` or no argument: require verification evidence, activate Stage D, and apply the P0–P3/confidence/verdict review contract. Use read-only task fan-out only when a compatible extension is detected; otherwise review sequentially with the saved independent model.

Never fix findings in the review pass. A block verdict returns to planning or B with a recorded countermeasure.
